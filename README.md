# The Cricketer — Module 0

Production-ready game design + data specification for the web-first cricket career RPG.

Module 0 defines the source-of-truth contracts for player attributes, cricket rules, progression, career, economy, equipment, AI, rewards, security, analytics, balancing, and future asset integration.

## Scope
This repository intentionally begins with design/data foundations. Module 0 contains no frontend, Phaser match scenes, multiplayer networking, or final database migrations.

## Structure
- `docs/game-design/` — system specifications and completion report
- `packages/game-core/src/types/` — shared strict TypeScript contracts
- `packages/game-core/src/config/` — editable balance/config definitions
- `packages/game-core/src/seed/` — initial conforming game data
